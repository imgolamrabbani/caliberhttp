CaliberHTTP Documentation

Get started in under 30 seconds—no login, no cloud sync, and full compatibility with plain-text .http files.

1. 30-Second Quickstart

  1. Install CaliberHTTP from the VS Code Marketplace, Open VSX, or download the .vsix directly from GitHub Releases (v1.0.0).
  2. Click the CaliberHTTP icon in the Activity Bar.
  3. If your workspace already contains .http or .rest files, they appear automatically. Otherwise click Create Starter Collection (api.http).
  4. Click ▶ Send Request above any request block—or ◫ Open in Studio for the split visual editor.

2. .http Syntax Reference

### Create User
@name createUser
@base = https://httpbin.org

POST {{base}}/post
Content-Type: application/json
X-Trace-Id: {{$uuid}}

{
  "createdAt": "{{$timestamp}}",
  "role": "developer"
}

@assert status == 200
@assert latency < 1000
@assert body.$.json.role == "developer"
  • ### Title — Separates requests and names them in the sidebar & CodeLens.
  • @var = value — File-scoped variables.
  • @name stepId — Names a request so later requests can reference {{stepId.response.body.$.field}} or {{stepId.response.headers.x-token}}.
  • @assert target op value — Supports status, latency, header.<name>, and body.<jsonpath> with ==, !=, <, <=, >, >=, contains, exists.

3. Environments & Dynamic Variables

Place a caliber.env.json or .env file in your workspace root and switch active environments from the top Studio bar or status bar:

{
  "dev": { "baseUrl": "http://127.0.0.1:3000" },
  "staging": { "baseUrl": "https://staging.api.example.com" }
}

Built-in dynamic variables: {{$uuid}} and {{$timestamp}}.

4. Pro Features Guide

  • Multi-Step Request Chaining: Run an entire .http file sequentially via ▶ Run Chain CodeLens and export JUnit XML, Markdown, or JSON test reports.
  • Schema Drift Detector: Pin any JSON response as a baseline. Subsequent runs flag removed fields, added fields, or breaking type changes.
  • Local 127.0.0.1 Mock Server: Start a local node:http mock server from any .http fixture file or OpenAPI 3.0/3.1 JSON spec.
  • HAR-to-.http Importer: Import browser DevTools .har captures into clean, deduplicated .http collections with automatic {{baseUrl}} extraction.
  • AES-256-GCM Secret Vault: Encrypt sensitive tokens in .caliber/vault.enc using PBKDF2-SHA256 + AES-256-GCM so secrets can be safely committed.
