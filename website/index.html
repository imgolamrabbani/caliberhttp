Frequently Asked Questions

Do I need an account to use CaliberHTTP?

No. Free features require zero sign-in and zero network access. Pro licenses use a Polar.sh license key stored locally in your OS Keychain via VS Code SecretStorage, with a 14-day offline grace period.

Does it work with my existing REST Client .http files?

Yes. CaliberHTTP parses standard ### request separators, @var definitions, @name references, and .env / caliber.env.json environments.

Can I use CaliberHTTP in Cursor, Windsurf, or VSCodium?

Yes. CaliberHTTP is published to both the VS Code Marketplace and the Open VSX Registry, so it installs natively in VS Code, Cursor, Windsurf, VSCodium, and Trae.

What happens if my internet drops while using Pro?

CaliberHTTP caches your license validation locally for 72 hours and provides a 14-day offline grace window so you are never locked out on flights, VPNs, or air-gapped networks.
