# CaliberHTTP Static Storefront (`website/`)

100% static `$0` storefront ready for instant deployment on **GitHub Pages** or **Cloudflare Pages**.

## 3-Step GitHub Pages Enablement

1. Push this repository to GitHub (ensure `website/.nojekyll` is committed).
2. Open your repository on GitHub → **Settings** → **Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch** (or GitHub Actions) and point to your `main` branch `/website` folder (or copy `website/` into `docs/` / root on `gh-pages`), then click **Save**.

Your storefront will be live at `https://<your-username>.github.io/<repo-name>/` with zero hosting cost.
