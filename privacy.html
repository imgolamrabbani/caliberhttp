Privacy Policy

Effective Date: November 27, 2026

CaliberHTTP is built on a strict zero-telemetry, 100% local-first architecture.

1. Zero Telemetry & Zero Analytics

The CaliberHTTP extension does not collect, log, or transmit usage analytics, crash reports, IP addresses, request payloads, response bodies, or workspace file names to our servers or any third-party analytics service.

2. Local-Only Data Storage

  • Collections & Environments: Stored as plain-text .http, .rest, caliber.env.json, and .env files directly in your local workspace.
  • Request History & Snapshots: Stored locally on your machine inside your workspace/VS Code storage.
  • Encrypted Secrets: Optional AES-256-GCM vault files (.caliber/vault.enc) are encrypted locally on your device.
  • License Key: If you activate Pro, your Polar.sh license key is stored in VS Code's OS-Keychain-backed SecretStorage.

3. Outbound Network Requests

CaliberHTTP makes zero background network requests. Outbound network connections occur strictly in two cases:

  1. User-Initiated HTTP Requests: Requests you explicitly trigger in the editor or Studio are sent directly from your machine to the target URL you specified.
  2. Optional Pro License Validation: When you activate, validate (every 72 hours if online), or deactivate a Pro license key, CaliberHTTP communicates with Polar.sh (https://api.polar.sh/v1/customer-portal/license-keys/*) sending only your license key, organization ID, and device hostname label.

4. Website & Payments

This static website is hosted on GitHub Pages with zero tracking cookies. Optional Pro purchases are processed by Polar.sh as Merchant of Record under Polar.sh's privacy policy.
